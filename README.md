# Krishna Yaswanth Portfolio

Personal portfolio showcasing frontend engineering work across enterprise React and Next.js products.

## Tech Stack

- Next.js (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- next-themes

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality Checks

```bash
npm run lint
npm run build
```

## Deploy on Vercel

1. Push this repository to GitHub (`yaswanthdk/krishna-yaswanth-portfolio`).
2. Import the project in [Vercel](https://vercel.com/new).
3. Use the default settings:
   - **Framework Preset:** Next.js
   - **Build Command:** `npm run build`
   - **Output Directory:** (default)
4. Deploy.

### Custom domain

After the first deploy:

1. In Vercel → **Project → Settings → Domains**, add `krishnayaswanth.com` (and `www` if needed).
2. Update DNS at your registrar using the records Vercel provides.
3. Confirm `constants/site.ts` → `url` matches your live domain (currently `https://krishnayaswanth.com`).

SEO routes generated by the app:

- `/sitemap.xml`
- `/robots.txt`
- Open Graph image at `/opengraph-image`
- Favicon via `/icon`

## Environment Variables

No environment variables are required for the current setup. Site URL and social links live in `constants/site.ts`.
